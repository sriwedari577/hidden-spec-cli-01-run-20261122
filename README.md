`mend` is one patch tool for every AI edit format: it reads unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls, finds the lines each edit names at three matching tiers (exact, trailing-whitespace, indentation-drifted), and changes every file or none.

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```

Node 22, standard library only. Practice score: 100 of 100 checks.
